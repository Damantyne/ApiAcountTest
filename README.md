# 💰 Savings API (.NET 8)

API RESTful desarrollada en C# y ASP.NET Core para la gestión de cuentas de ahorro personales.

---

## 🚀 Características

- 📊 **Consulta de Saldo:** Obtén el saldo actualizado de cualquier cuenta en tiempo real.
- 💵 **Depósitos:** Añade fondos a una cuenta de ahorros.
- 💸 **Retiros con Validación:** Permite extraer dinero validando que el monto solicitado no exceda el saldo disponible.
- ⚡ **Persistencia Thread-Safe:** Uso de `ConcurrentDictionary` para garantizar la consistencia de datos en memoria sin base de datos externa.
